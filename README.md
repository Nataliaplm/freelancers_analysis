## Descripción del proyecto
Análisis del dataset Global Freelancers, que contiene información de 1000 trabajadores freelance de distintos países. El objetivo es identificar qué características de un freelancer se asocian a su desempeño percibido por el cliente.

---

## Ficheros del repositorio

| Fichero | Descripción |
|---|---|
| `global_freelancers_raw.csv` | Dataset original sin modificaciones |
| `global_freelancers_clean.csv` | Dataset limpio tras aplicar las transformaciones |
| `Global_freelancers_Reto_4.R` | Script R con la limpieza, análisis y visualizaciones |
| `PRACT2_Tipologia.pdf` | Memoria de la práctica con las respuestas a todos los apartados |

---

## Instrucciones para ejecutar el código

1. Abrir RStudio
2. Cargar el archivo `Global_freelancers_Reto_4.R`
3. Ir a **Session → Set Working Directory → To Source File Location**
4. Ejecutar el script completo
5. Si `factoextra` no está instalado, descomentar la línea 8 y ejecutarla primero

---

## Requisitos
- R versión 4.4 o superior
- Paquetes: `factoextra`, `car`, `cluster`
